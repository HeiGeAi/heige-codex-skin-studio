# macOS 启动器控制与修复实现计划

1. 先为 `launcher-close`、`launcher-repair`、两个固定包装脚本和 AppKit 控件补充失败测试。
2. 在 CLI 中实现版本绑定的关闭和修复命令，关闭走 `pause`，修复走强制重启并恢复最近主题。
3. 新增 `close-skin.command` 与 `repair-skin.command`，保持产品和端口固定映射。
4. 在产品卡增加打开和关闭操作，在底部增加一键修复及结果反馈。
5. 升级到 5.5.13，构建通用二进制，更新文档与发布证据。
6. 从最终归档覆盖安装，执行完整发布门禁并做只读界面验收。
