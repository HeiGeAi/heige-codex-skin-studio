# HeiGe Codex Skin Studio 5.5.11 验证记录

日期：2026-08-21

## 本轮范围

- 修复 macOS「HeiGe 皮肤启动器」窗口内置 Logo 仍复用 Dock 图标、视觉上没有真正更换的问题。
- 保持 Finder 与 Dock 的 `AppIcon.icns` 不变，新增只供窗口标题区域使用的 `LauncherLogo.png`。
- 从最终 `.skill` 安装包覆盖安装 5.5.11，并在当前 Mac 的 Dark 外观下重新打开正式启动器验收。

## 根因

5.5.8 只把字母「H」占位图替换成了 Bundle 的 `AppIcon.icns`。窗口标题区域和 Finder、Dock 仍读取同一资源，因此此前并没有实现“窗口内置 Logo 独立更换”。

## 修复

- 以当前 Miku 皮肤核心人物为参考，生成正方形上半身构图 `assets/launcher/LauncherLogo.png`，不再复用近脸裁切的 Dock 图标。
- 原生 AppKit 窗口改为读取 `LauncherLogo.png`，并将无障碍名称更新为「初音未来启动器内置 Logo」。
- Bundle 升级为 Schema 5，同时携带 `AppIcon.icns` 与 `LauncherLogo.png`。
- 新 Logo 纳入 PNG 文件头与尺寸校验、固定资源白名单、0644 权限校验、签名校验和确定性打包。
- 保留 Schema 4 读取兼容，现有安装可以直接覆盖升级到 Schema 5。
