# v5.5.7 WorkBuddy 专家团弹层实底修复验证记录

## 问题与根因

- 复现场景：WorkBuddy 5.3.14，打开「专家·技能·连接器」中的专家团详情弹层。
- 弹层稳定类名为 `.ec-modal-card`，原生背景为 `var(--wb-bg-primary)`。
- 皮肤为了让 WorkBuddy 主画布透出壁纸，会将 `--wb-bg-primary` 设为透明。
- 既有实底浮层名单没有包含 `.ec-modal-card`，因此后方专家卡片与文字穿透到弹层正文。

## 修复边界

- 仅将 `.ec-modal-card` 加入实底浮层名单，背景使用 `var(--heige-solid)`。
- 不修改全局 `--wb-bg-primary`，避免破坏主画布壁纸效果。
- 不修改 `.ec-modal-overlay`，继续保留弹层外部半透明黑色遮罩。
