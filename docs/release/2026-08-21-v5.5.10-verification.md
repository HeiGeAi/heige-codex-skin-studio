# HeiGe Codex Skin Studio 5.5.10 验证记录

日期：2026-08-21

## 本轮范围

- 修复 macOS 外观切换后皮肤启动器文字与 Layer 背景不同步，导致夜间模式对比度不足的问题。
- 保持已确认的双产品卡片布局、最近皮肤恢复逻辑、9341 与 9342 端口隔离不变。
- 重新构建、打包并覆盖安装 5.5.10。

## 根因

旧启动器的标题和辅助文字使用 AppKit 动态语义色，会自动跟随 `effectiveAppearance`。窗口、产品卡片、最近皮肤区域和 Logo 边框却在初始化时把动态 `NSColor` 立即转换成固定 `CGColor`。当前旧进程已连续运行约 9 小时，系统后来切换为 Dark 后，文字已经更新，Layer 颜色仍保留旧值，形成低对比度界面。

## 修复

- 新增 `AppearanceSurfaceView`，保存语义背景色与边框色。
- 在 `viewDidMoveToWindow` 和 `viewDidChangeEffectiveAppearance` 中，通过 `effectiveAppearance.performAsCurrentDrawingAppearance` 重新解析 Layer 颜色。
- 窗口、产品卡片、最近皮肤区域和 Logo 边框统一使用该外观感知容器。
- 主标题、产品标题和主题名明确使用 `labelColor`；辅助信息继续使用 `secondaryLabelColor`；按钮继续使用 AppKit 原生自适应样式。

## 真实窗口验收

- 当前系统 `AppleInterfaceStyle` 为 `Dark`。覆盖安装后重新打开正式启动器，标题、卡片、最近皮肤区域、按钮、状态和辅助说明均清晰可读。
- 使用 `/tmp` 中的临时 App 副本增加 `NSRequiresAquaSystemAppearance=true` 并更换测试 bundle id，在不修改系统全局外观的情况下验证 Aqua 浅色窗口，全部内容清晰可读。
- 浅色测试实例关闭后，正式启动器已恢复为跟随系统的 Dark 实例。
- 两种窗口的无障碍树都完整包含 Codex、WorkBuddy、两个操作按钮和诊断入口。
