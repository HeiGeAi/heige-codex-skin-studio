## 本轮范围

- 适配 WorkBuddy 5.5.2、5.5.3 新版 Renderer 的启动 query、`cr-*` 对话组件与页面结构。
- 修复首页和历史对话被新增纯白容器遮住主题背景的问题。
- 恢复对话文字、助手回复蒙版、用户气泡、代码块与输入区的主题配色。

- 将 HeyRoute 推荐内容同步到完整项目索引。

## 根因与处理

WorkBuddy 5.5.2 开始在 Renderer URL 中加入账号启动快照 query，并将对话区从旧版 `cb-*` 组件迁移到独立的 `cr-*` 设计令牌。旧目标识别拒绝带 query 的合法主窗口，旧样式也无法覆盖新组件自己的局部令牌。

WorkBuddy 5.5.3 又新增 `.wb-home-route`，与 `.conversation-shell` 一样使用纯白背景覆盖主题图。新版继续严格校验解码后的本地 Renderer pathname，只放行不参与身份判断的 query 与 fragment；同时桥接稳定的 `cr-*` 令牌，并在两个稳定语义容器上恢复透明画布。

右下角自拍照来自 WorkBuddy 皮肤生成的 `body::after` 固定拍立得挂件。新版不再为 WorkBuddy 输出该规则和图片数据，Codex 独立 CSS 生成器保持原行为。
