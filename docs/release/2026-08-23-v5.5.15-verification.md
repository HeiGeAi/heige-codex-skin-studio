## 根因

WorkBuddy 的桥接样式使用通用选择器 `[class*="dialogContainer"]` 和 `!important`，把所有 CSS Modules 确认框背景绑定到 `--wb-bg-primary`。皮肤为了让主画布显示壁纸，会把这个令牌设置为透明。

权限确认框的结构是 `_dialogOverlay_<构建哈希>` 直接包裹 `_dialogContainer_<构建哈希>`。旧规则只覆盖固定语义类名和 `*-dialog-overlay`、`*__dialog-overlay` 形式，因此没有命中 camelCase CSS Modules 类名。

新版使用 `body.agent-ui-theme [class*="dialogContainer"]` 对齐宿主自己的稳定语义片段并提高特异性，不依赖构建哈希。规则只给确认框卡片恢复 `--heige-solid` 实底，不修改 `[class*="dialogOverlay"]` 遮罩。
